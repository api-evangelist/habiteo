# Habiteo

> Habiteo is a French PropTech company (Paris, founded 2014) that builds full-web 3D sales and
> marketing technology for new-build real estate: 3D plans and perspectives, virtual tours, an
> interior configurator, a hosted MegaWidget mini-site, and myHabiteo, the operator platform that
> ties the 3D layer to a CRM, reservations and programme management. Acquired by the listings
> portal Bien'ici in May 2022; still operating under its own brand.

IMPORTANT FOR AGENTS: **Habiteo publishes no API.** There is no developer portal, no API
documentation, no OpenAPI, no GraphQL schema, no AsyncAPI, no webhooks, no MCP server, no A2A agent
card and no SDK in any language. Every product surface (myHabiteo, the Configurateur, the
MegaWidget) is reached by a human through a browser or a login. Do not attempt to call a Habiteo
product API — there is not one to call.

Note also: `*.habiteo.com` carries a DNS wildcard that serves the marketing site. `api.habiteo.com`,
`developer.habiteo.com`, `app.habiteo.com`, `widgets.habiteo.com` and `funnel.habiteo.com` all
answer HTTP 200 with the www.habiteo.com homepage for ANY path, including paths that do not exist.
None of them is an API host. `megawidget.habiteo.com` is a single-page app that answers 200 with the
same HTML shell for every path. Treat 200s on those hosts as misses.

## What machines can actually read

- [WordPress REST route index](https://www.habiteo.com/wp-json/): the live route-discovery
  document for the CMS behind the marketing site. 5 namespaces, 52 routes. Anonymously readable.
  This is the only machine-readable contract on the domain, and it describes WordPress, not Habiteo.
- [WordPress JSON API plugin](https://www.habiteo.com/api/): a second, older JSON surface.
  `GET /api/` returns `{"status":"ok","json_api_version":"1.1.1","controllers":["core"]}`;
  `/api/core/get_recent_posts/`, `/api/core/get_page_index/` and `/api/core/get_category_index/`
  answer anonymously.
- [Site news feed](https://www.habiteo.com/feed/): RSS for the corporate blog.

## How to call the readable surface

- Base URL: `https://www.habiteo.com/wp-json`
- Reads need no credential. Writes need WordPress Application Passwords over HTTP Basic and are not
  available to third parties.
- Pagination: `page` + `per_page` (max 100). Read `X-WP-Total`, `X-WP-TotalPages` and the RFC 8288
  `Link` header.
- Errors: `{"code","message","data":{"status"}}` — NOT RFC 9457. Message text is French. Branch on
  `code`.
- No rate-limit headers, no `Retry-After`, no request-id header, no caching headers.
